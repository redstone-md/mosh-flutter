# Start menu illustrations

Generated with ChatGPT image generation on 2026-10-07 for IVO-50, with
transparent backgrounds, then resized for the app: `hero.png` to 1254px
wide, the step tiles to 512px square.

- `hero.png`: glass cube with the Mosh mark, linked to chat, people, link
  and `#` tiles.
- `chat.png`, `group.png`, `join.png`, `channel.png`: one glass tile per
  step.

Each prompt starts with this common block, followed by its subject:

```text

Premium restrained 3D translucent smoked-black glass, lime green light (#B7D84A base, #95ee45 luminous highlights), fine silver-white outlines, rounded corners, subtle depth. Thin elliptical orbital ribbons, small lime particles and delicate dotted arcs. Render on a genuinely TRANSPARENT background with preserved soft transparent glow, no dark background rectangle, no text, no labels, no letters, no watermark, no extra composition outside subject. Generous transparent margins, nothing cropped at the edges. Designed to look sharp and elegant on a #0B0C0D background. Use one consistent material, camera angle and lighting style for a series of five illustrations.
```
