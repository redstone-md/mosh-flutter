All 859 Rust weights resolve with the original shipping symbols. Matching
Go ranges resolve 1,541 of 1,542 Moss weights; one stays unassigned. Rust leaves
include allocation (76), curve arithmetic (67 and 66), and JSON escaped-string
encoding (36). Go leaves include copying (71), GC object scanning (49), JSON
string encoding (43) and `MeshInfoJSON` (25). These identify observed work,
not allocating callers, redundant verification or retained objects. Inlined
function names do not substitute for complete call chains. No statistical
sample share is converted into an OS process CPU share or predicted saving.

Approximate alignment of the 88 adjacent CPU intervals and network buckets
gives zero-lag Pearson correlation 0.243, assuming uniform bytes within each
second. Lowest/highest traffic quartiles contain 22 intervals each, with median
0.306/1.093 Mbit/s and 6.18%/7.74% one-core CPU. This limited association does
not establish a causal network bottleneck or justify changing discovery cadence.

## Acceptance status

This is the first supplied physical-desktop capture of the readiness integration.
It confirms the intended installed binaries and records lower CPU/working set
in this window. It does not isolate the patch's whole-process effect, confirm
long-run budgets or reproduce the original intermittent high-throughput event.
No new runtime patch, merge, release or repeated recording is requested here.

Issue #94 remains open. Android background incoming-call delivery is not
implemented by this update; phone lifecycle and battery acceptance remain
separate outstanding work. Raw diagnostics, original binaries and symbols stay
private; this report contains aggregate findings only.
