All 1,030 Rust weights resolve against the original DLL/PDB. The attached Go
function ranges map 1,932 of 1,934 Moss weights; two stay unresolved. The
equivalent preceding Rust and Moss raw counts are 1,261 and 1,455. For a
consistent curve-math comparison, select Rust instruction rows having any
inline function name containing `curve25519_dalek::`: this yields 502 weights
before and 207 now. This narrower literal-name predicate differs from the
earlier broad arithmetic classification. Lower Rust/arithmetic observations
are consistent with the focused correction, but do not measure cache hits or
prove which current callers request the remaining arithmetic.

Remaining leaves include allocation, JSON/bridge encoding, curve math and Go
memory/GC/mesh-info work. Flat leaves cannot distinguish key derivation from
signature checking, or establish duplicate polling, a rendering defect or a
new network-policy change. Reusing the old build's caller paths or RVAs would
be invalid. The next discriminating artifact is selected-PID caller paths from
this capture's existing ETL, using the original `82cc774e` symbols. No new
runtime optimization is introduced on this evidence alone.
